# Sudoku 2.0.0

- Renamed app to **Sudoku**; removed home title and headline.
- Email/password accounts, profile saving, sign-out, session refresh, and password changes.
- Live all-time / weekly scoreboard with difficulty filters and your rank.
- Server-issued ranked games, move validation, and duplicate-score protection.
- Thirty harder levels: 1,000 XP to level 2, then +350 XP more per level.
- Rewards at every level: avatars, backgrounds, animated backgrounds, frames, themes, titles, and real Android launcher icons.
- Existing XP, saves, and earned themes preserved. The nine-pencil-mark sizing fix remains.

Download **Sudoku-2.0.0.apk** and install over the existing app. Same package and signing key; no uninstall needed. Android 8.0+.

Signup is immediate without email verification, as approved. Password-reset emails remain unavailable until an SMTP provider is configured.

Live backend tests, mobile browser checks, signed build, and Android lint passed. Physical Android runtime and launcher-icon behavior remain unverified.
