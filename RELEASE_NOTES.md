# Inkoku 1.0.0

Offline Android Sudoku with seven difficulties, three lives, pencil marks, undo, autosave, and pause.

Earn XP, stars, daily streak bonuses, seven ranks, four themes, and six achievement badges. Daily challenge awards a once-per-date bonus. Screens use titles and functional labels without subtitles.

## Install

Download **Inkoku-1.0.0.apk** below. Requires Android 8.0+. This is a signed release APK; Android may ask you to allow installation from your browser or file manager.

**SHA256SUMS.txt** contains the APK checksum. Source archives are available below.
